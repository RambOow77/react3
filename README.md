# Hito 3 - Pizzería Mamma Mía

Proyecto React + Vite preparado para el Hito 3 de Desafío Latam.

## Ejecutar

1. Abrir una terminal dentro de esta carpeta.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev`.
4. Abrir la dirección que indique Vite.

## Archivos principales

- `src/App.jsx`
- `src/pizzas.js`
- `src/components/Home.jsx`
- `src/components/CardPizza.jsx`
- `src/components/Cart.jsx`
- `src/components/Navbar.jsx`
- `src/components/Footer.jsx`

## Carrito

Para mostrar el carrito como vista principal, en `src/App.jsx` comenta `<Home />` y descomenta `<Cart />`, tal como indica el enunciado del Hito 3.

## Nota sobre pizzas.js

El PDF del Hito 3 indica que el archivo `pizzas.js` debe venir del material de apoyo, pero el contenido exacto de ese archivo no aparece dentro del PDF. Por eso esta entrega incluye un `pizzas.js` compatible con los componentes y con seis pizzas para poder ejecutar y revisar el proyecto.
